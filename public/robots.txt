# Cloudflare's Managed robots.txt prepends its own block above this one at the
# edge, which means the file served to crawlers contains two `User-agent: *`
# groups. The spec says to merge them and the major crawlers do, but not every
# parser is well behaved. So the named groups below are repeated here rather
# than left to that injection: a named group beats `*` in every parser, and
# repeating them keeps the archive protected if the Cloudflare toggle is ever
# turned off. Redundant on purpose.
